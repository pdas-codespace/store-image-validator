# Storefront inspection

- Full view: both side edges of the unit facade and the entrance must be in frame. An approved plaza directory sign showing the brand panel is an accepted alternative when the rule lists it.
- Branding legibility: read the sign text letter by letter. If any letter of the brand name must be guessed, use CANNOT_DETERMINE.
- Window and door graphics: check doors and windows separately. A door outside the frame means CANNOT_DETERMINE, not FAIL.
- Previous-tenant remnants: look only at the band immediately around the brand sign (ghost lettering, old logo brackets, paint outlines). Ignore remnants on other parts of the facade, neighbouring units, and temporary seasonal banners.
- Glass reflections can look like graphics. Prefer CANNOT_DETERMINE over guessing when reflections dominate.
